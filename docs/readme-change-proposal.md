# README 待确认调整清单

本文档只记录建议口径，不直接修改 README。README 项目结构说明保留，不作为问题处理。

## 建议保留的主线表述

- 继续说明本扩展用于网页图片采集、筛选、预览、复制、下载和 ZIP 打包。
- 继续说明支持 Popup 快速操作和 Workspace 批量整理。
- 继续说明漫画模式是实验性增强能力，适合按阅读顺序整理当前页和用户确认加载的后续分页。

## 建议补充或收窄的能力口径

- ZIP 分卷设置：说明入口在 Workspace，Popup 批量 ZIP 使用当前全局设置。
- 自动采集：说明会监听常见懒加载字段和动态新增图片，但复杂站点仍可能需要手动继续扫描或滚动辅助。
- 漫画后续分页：说明后续分页需要用户点击加载；扩展会在每页等待上限内尝试触发基础懒加载，但不承诺所有站点全量无损。
- 隐藏图片：说明隐藏状态会在当前采集会话中保存；Workspace 可通过“隐藏”筛选查看或恢复，Popup 默认不显示隐藏图片。

## 建议补充的限制说明

- 对登录态、强防盗链、脚本延迟加载、内层滚动容器、canvas/blob 或虚拟列表页面，扩展只能尽力采集可访问资源。
- 大批量 ZIP 仍建议使用默认或更稳的分卷设置；超大分卷会提高内存压力。
- 后续分页加载保持用户确认，不会进入漫画模式后自动无限抓取。
