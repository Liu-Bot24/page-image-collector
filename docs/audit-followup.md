## 验证边界

- 兼容预览后台总并发为 4，单图响应上限 16 MiB，已知 Content-Length 超限时提前取消，流式响应超限时停止读取。超过限制的候选会继续回退；所有候选都超限或不可用时会显示加载失败。普通下载不采用此预览大小限制。
- 201 条容量场景已验证列表与卡片可用；网站自身的登录、令牌过期或额外防盗链策略仍可能让所有候选失败。现有规则池不会因此扩展为无限容量。
- 恢复依赖持久 downloadId；浏览器已创建下载但尚未保存 ID 的极窄重启窗口仍报告结果未知，避免重复下载。旧任务缺失会话标识时可以恢复下载观察，但不能修改新采集记录。
- 元数据存储仍为整体快照，大量记录仍可能达到配额；本轮移除了下载恢复记录中的图片字节，没有迁移到 IndexedDB 或按记录分片。
- ZIP 单文件及跨任务总内存预算、iframe 全覆盖、关闭的 Shadow Root 未在本轮重构。原有非活动页测试没有实际触发 RAF 完全暂停，相关条件仍由确定性测试覆盖。
