# 图片采集查看器

Languages: [简体中文](README.md) · [English](README-en.md)

</div>

一款面向日常浏览场景的 Chrome 扩展，用于快速采集网页图片，并提供筛选、查看、批量复制、批量下载与 ZIP 打包能力。

## 功能特性

- 多来源采集：支持 `img`、`picture`、`srcset`、常见 `data-*` 懒加载字段、背景图等常见图片来源
- 增量采集：支持手动继续扫描与自动采集，适合信息流、瀑布流、无限滚动页面
- 漫画模式：实验性功能，通过右键菜单或 Popup 入口进入，图片按 DOM 顺序排列，支持自动检测分页并逐页加载后续页面图片
  - 分页检测基于页面结构启发式分析，部分非常规分页结构可能无法识别
  - 自动获取后续分页时，每页仅采集已加载的图片内容；若目标页面依赖滚动触发懒加载，未进入视口的图片可能不会被采集
- 自动滚动：Popup 提供自动滚动入口，适合配合自动采集处理长列表和无限滚动页面，也可独立使用
- 智能归并：自动规整常见参数差异、尺寸变体与部分原图链接
- 精细筛选：支持格式筛选、分辨率预设、最小短边、最小长边、最小像素阈值
- 双界面工作流：Popup 适合快速操作，Workspace 适合大批量筛选与沉浸式看图；两者共享同一标签页结果集
- 批量处理：支持批量复制链接、逐张批量下载、ZIP 打包下载
- 图片查看：支持普通预览、键盘切换、Workspace 全屏查看
- 来源回溯：支持从采集图片打开来源页面
- 下载反馈：批量下载和 ZIP 打包过程会显示当前进度，便于观察长任务状态
- 本地运行：不依赖外部后端服务，数据保存在浏览器本地环境

## 界面说明

### Popup

适合快速完成以下操作：

- 扫描当前页面
- 快速筛选图片
- 启动自动滚动
- 批量复制链接
- 批量下载
- 打开 Workspace 继续处理
- 进入漫画模式
- 启用页面右键解锁

说明：Popup 属于浏览器扩展弹窗，离开弹窗焦点后会自动关闭。已经启动的自动采集、自动滚动和下载任务仍会继续运行，结果可稍后在 Popup 或 Workspace 中继续查看。

### Workspace

适合处理更复杂的采集任务：

- 大批量浏览与筛选
- 选区式多选
- 更沉浸的预览体验
- 全屏查看与切换
- 批量下载与 ZIP 打包
- 漫画模式：阅读顺序排列、自动分页检测与加载
- 布局切换：支持网格与瀑布流两种浏览模式
- 承接 Popup 已采集结果，继续筛选与处理

## 使用方式

### 手动扫描

- `开始扫描`：建立当前页面的图片结果集
- `继续扫描`：在现有结果基础上增量补充新图片，并更新更优版本
- `清理`：清空当前标签页结果，重新建立新的采集结果集

### 自动采集

- 开启后监听页面新增图片节点，自动增量加入结果集
- 适合动态加载页面，例如信息流、长列表、瀑布流页面
- 建议先手动扫描一次，再开启自动采集

### 自动滚动

- 入口位于 Popup 顶部，位于“自动采集”左侧
- 可单独使用，也可与自动采集配合使用
- 适合需要持续向下加载内容的页面，例如长列表、瀑布流、信息流页面
- 启动后即使 Popup 关闭，当前标签页内的采集任务仍会继续执行
- 采集结果会持续汇总到当前标签页结果集中，之后可直接打开 Workspace 查看和处理

### 筛选能力

- 格式：`JPG / PNG / WebP / GIF / SVG / AVIF / 其他 / 隐藏`
- 分辨率预设：`全部 / ≥720P / ≥1080P / ≥2K / ≥4K`
- 自定义阈值：
  - 最小短边
  - 最小长边
  - 最小像素（MP）
- 常用开关：
  - 采集原图
  - 大到小排序
  - 仅显示竖图
  - 下载转 JPG
  - 批量下载 ZIP
  - 自动滚动（Popup）
  - 自动采集
  - 解锁右键（Popup / 右键菜单）

## 下载与复制

### 单图下载

- 按当前“采集原图”设置选择下载源
- 开启“下载转 JPG”后，会在适用时转换为 JPG 再下载

### 批量下载

- 非 ZIP 模式下，图片会逐张加入浏览器下载队列
- 开启“下载转 JPG”后，会对可转换格式执行 JPG 转换
- 批量任务进行中会显示当前进度状态

### 批量 ZIP 下载

- `批量下载 ZIP` 默认关闭，按需手动开启
- 批量任务会输出 ZIP 文件，适合集中归档
- 大批量任务会自动分卷，并按卷依次下载
- 打包与下载过程会显示当前卷和整体处理进度
- 文件名规则：
  - 单卷：`域名-YYYYMMDD-HHMM-images.zip`
  - 分卷：`域名-YYYYMMDD-HHMM-images.part001.zip`
- 自动分卷条件：
  - 单卷约达到 `192MB`
  - 或单卷达到 `300` 张图片

### 复制策略

- 优先复制图片本体到剪贴板
- 当浏览器权限或格式限制不允许时，自动回退为复制图片链接

## 右键菜单

- 页面空白处（子菜单）：
  - 扫描当前页面图片
  - 扫描当前页面图片（漫画模式）
  - 解锁右键
- 图片元素上（子菜单）：
  - 查看原图
  - 复制原图
  - 下载原图

## 安装

### 从 Chrome 网上应用店安装（推荐）

[图片采集查看器 - Chrome Web Store](https://chromewebstore.google.com/detail/%E5%9B%BE%E7%89%87%E9%87%87%E9%9B%86%E6%9F%A5%E7%9C%8B%E5%99%A8/jchjkamalmegomjijigapilnecdccbom)

### 从 GitHub Releases 安装

1. 进入项目的 `Releases` 页面
2. 下载对应版本的解压包，例如 `page-image-collector-1.2.4-unpacked.zip`
3. 打开 `chrome://extensions/`
4. 开启“开发者模式”
5. 解压下载的 ZIP 文件
6. 点击“加载已解压的扩展程序”
7. 选择解压后的扩展目录

## 快速开始

1. 打开目标网页
2. 点击扩展图标，进入 Popup
3. 点击 `开始扫描`
4. 按需启用格式筛选、分辨率预设或自定义阈值
5. 根据需要执行以下操作：
   - 批量复制链接
   - 批量下载
   - 打开 Workspace 继续筛选与查看

对于动态页面，建议先执行一次手动扫描，再按需开启自动采集和自动滚动。

## 项目结构

- `manifest.json`：扩展配置（Manifest V3）
- `background/background.js`：消息调度、下载、打包、右键菜单、运行时协调
- `background/stateManager.js`：按标签页管理图片、选中状态与配置状态
- `content/content.js`：页面扫描、自动采集、自动滚动、页面侧能力处理
- `popup/*`：Popup 界面、快速筛选与自动滚动入口
- `workspace/*`：Workspace 界面与交互
- `styles/*`：样式资源

## 权限说明

- `activeTab` / `scripting`：向当前页面注入脚本并执行采集逻辑
- `downloads`：下载单图、批量下载、ZIP 下载
- `contextMenus`：提供右键菜单能力
- `storage`：保存标签页采集状态与界面配置
- `clipboardWrite`：复制图片或图片链接
- `declarativeNetRequest` / `declarativeNetRequestWithHostAccess`：处理部分图床请求兼容
- `host_permissions: <all_urls>`：支持在绝大多数常见网页中执行采集

## 适用范围与限制

- 浏览器受限页面不可注入，例如 `chrome://*`、扩展管理页、Chrome Web Store 等页面
- 纯 Canvas / WebGL 渲染内容通常无法直接提取原图
- 强防盗链、临时签名链接或受限图床可能导致原图链接不可直接下载
- 部分站点需要先展开详情区域或加载更多内容后，才能获得完整图片结果
- 大型动态页面开启自动采集时，可能带来一定性能开销
- Popup 受浏览器扩展弹窗机制限制，离开焦点后会自动关闭；长时间观察、批量筛选和集中处理建议在 Workspace 中完成
- 大批量 ZIP 下载会占用较多浏览器资源，卷数和耗时会随页面图片体积变化
